# Map surfaces

Photoscanned CC0 PBR scans from Poly Haven, fetched with
`python3 tools/dev.py fetch --domain maps` (pinned in `content/asset_sources/maps.json`,
hashes in `maps.lock.json`, provenance in `content/manifest/maps.json`). Each folder holds
diffuse, OpenGL normal and ARM (AO, roughness, metal) maps at 2K (1K for small props);
ground scans also carry a height map for layer blending. Ground UVs stay fixed as the camera moves; view-dependent parallax is disabled.

`surface.gdshader` renders architecture on metric UVs with grime and edge wear from
vertex colours; `ground.gdshader` blends four scans for ground and terrain;
`foliage.gdshader` renders the fir branch cards. `game/maps/map_surfaces.gd` lists each
scan's real-world size. `fabric_*` are generated by `tools/generate_fabric.py`.

`grass_clump/` holds the ground-grass clump atlas (colour, opacity, normal), generated from the
CC0 ambientCG Foliage001 blades by `tools/generate_grass_clumps.gd`; `grass_clump.gdshader` renders it.
