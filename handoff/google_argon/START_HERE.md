# Google Argon map creation handoff

Give Argon the accompanying `google_argon_map_handoff.zip`, paste `ARGON_PROMPT.md`, and grant access to a copy of the FPS Mode repository when implementation begins. The ZIP contains project source context and asset provenance, not the binary art library, engine, or a runnable game. For actual creation and verification, use the full repository with its existing `content/` assets and pinned `.tools/` setup; run `python3 tools/dev.py setup` if that setup is absent. Do not upload secrets or account credentials.

Recipient name “Google Argon” is taken from the request; no particular Argon API, upload format, or integration is assumed. This package can be attached to its project/workspace interface or supplied to its coding agent.

## Contents

- ARGON_PROMPT.md: ready-to-paste task and acceptance requirements.
- MAP_SPEC.md: original creative direction, coordinates, routing and production stages.
- source_context/: current project source, tests, tooling, registry examples and asset records, with original relative paths.
- FILE_INDEX.json: SHA-256 and byte size for every supplied source file.

The map concept is an editable default, not an earlier user-approved design. Scope defaults to a new TDM map because no theme or mode was specified. The source also includes Zombies examples for reference, but do not blend the two gameplay contracts.
